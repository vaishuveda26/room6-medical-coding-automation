# Medical Coding Automation

Monorepo starter structure for a medical automation system with:
- Python backend
- React frontend

## Quick Structure
- `backend/` Python API and business logic
- `frontend/` React UI

## Run With Docker Compose
1. From repo root: `docker compose up --build`
2. Backend API: `http://localhost:8000`
3. Frontend app: `http://localhost:5173`
